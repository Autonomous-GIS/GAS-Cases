Case 3

County-level map of 2021 population for the contiguous United States

In the third use case, we gave the system a high-level request: show the 2021 population by county across the contiguous United States. Unlike a fully specified GIS workflow, the request did not tell the coordinator which datasets, processing steps, join strategy, classification method, or specialized agents to use. The coordinator translated the request into a five-step workflow: retrieve U.S. county boundaries, filter them to the contiguous United States, retrieve county-level 2021 population data, join the population records to the county polygons, and generate the final choropleth map. The workflow used five agent executions across three specialized agent types: DataRetrieverAgent, VectorAnalysisAgent, and MappingAgent. It completed in 168.90 seconds with no replanning. This case demonstrates how GAS can turn a higher-level geospatial request into an explicit multi-agent workflow while preserving the data dependencies needed for the final map. In particular, the coordinator had to obtain compatible county geometry and population data, restrict the spatial extent appropriately, prepare the attributes for a reliable county-level join, and pass the resulting spatial dataset to the mapping service. The resulting workflow remains traceable because these intermediate transformations are represented as explicit service steps rather than hidden inside a single opaque operation.
